# Pencarian Jalur Kampus dengan Algoritma A*
Final Project Kecerdasan Buatan — Implementasi algoritma A* untuk
mencari jalur terpendek antar fakultas di lingkungan kampus.

# Fitur
- Pilih titik awal via dropdown
- pilih titik tujuan via dropdown
- Visualisasi peta kampus + jalur optimal
- Log langkah demi langkah (open set, closed set, g, h, f)
- Metrik evaluasi: total biaya, node dieksplor, , waktu eksekusi

# Cara Menjalankan
1. Install dependencies: `pip install -r requirements.txt`
2. Jalankan: `streamlit run app.py`

# Teknologi
- Python 3
- Streamlit
- NetworkX
- Matplotlib
- Pandas
